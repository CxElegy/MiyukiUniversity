# 受験通信

データはリポジトリ直下の `juken.yaml`、ページ `docs/index.html` は `scripts/juken.py` が作る（GitHub Actions でも2時間ごとに更新）。
ページは GitHub Pages で公開される。**学校名・クラス・フルネーム・住所など本人が特定できる情報は書かない**（名前は「美幸」だけ）。

## 志望校を追加する

1. 日程を調べる：WebSearch で、その大学の**令和9年度（2027年度）入試**の公式日程（募集要項・入試ガイド）を探す。
   今年の分が見つからなければ去年の日付を入れて `tentative: true`、`note` に「昨年度の日程（目安）」と書く。
   出願期間・試験日・合格発表・入学手続締切の4つは必ず。共通テスト利用もあれば入れる。
2. `juken.yaml` の `targets` に書く（項目の説明はファイル冒頭）。`short` は略称（カレンダーのマスに出る）、
   `url` は入試情報ページ。本当に大事な日（出願締切・試験日・手続締切）には `remind: true`（Discord で事前に通知）。
3. 確認：
   ```bash
   python scripts/juken.py render
   python -m unittest discover tests
   ```
   `docs/index.html` をスクリーンショットで確認（月カレンダー・ガントチャート・志望校カード）してから commit・push。

## 公式日程・変更点・おすすめ学部

`schedule`（公式日程）・`changes`（今年の変更点）には `source`（出典URL）を付ける。
うわさ・未確認のものは書かない。暫定とわかっているものは `tentative: true`。
`recommend` のボーダーは河合塾 Kei-Net など出典の年度を明記する。

## 逆算プラン

`plan` は期間（from〜to）ごとの目標と「やること」。今日を含む期間がページ上部の「いまやること」になる。
日程が変わったら、その前後の期間の `todo` も合わせて直す。
