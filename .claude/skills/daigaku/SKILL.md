# 日本の大学しらべ

美幸（高3・理系・地方国公立が第一志望、私大は東洋大・MARCH を押さえに検討）のために、
大学・学部の入試情報を**出典つきで**調べ、比べ、`juken.yaml` に反映する。

## 1. どこを見るか（信頼できる順）

| 何を | どこで |
|---|---|
| 日程・科目・配点・募集人員 | 大学公式の**募集要項**・**入試ガイド（PDF）**。2027年度版（令和9年度）かを必ず確認 |
| 共テボーダー得点率・二次偏差値 | 河合塾 Kei-Net `https://search.keinet.ne.jp/<大学コード>/general/border_rate`（「2027年度入試」表記を確認） |
| 入試の変更点 | Kei-Net `…/<大学コード>/general/exam_changes`、大学の「変更点」PDF |
| 合格発表日・手続締切 | 大学公式 → ベネッセ マナビジョン（`manabi.benesse.ne.jp/daigaku/school/<code>/nyushi/`）|
| 科目の早見・倍率 | 旺文社 パスナビ（`passnavi.obunsha.co.jp`）|
| 国公立の日程ルール | 国立大学協会「入学者選抜実施要領」、文科省「大学入学者選抜実施要項」|

予備校の数字は**予想値**。ブログ・まとめサイトの数字は使わない（使うなら「目安・二次情報」と明記）。

## 2. 何を集めるか（1学部につき）

- **日程**：出願期間／試験日／合格発表／入学手続締切（前期・中期・後期・共テ利用・一般の方式ごと）
- **共テ**：必要な教科・科目、配点（傾斜があれば書く）、二段階選抜（足切り）の有無と目安
- **二次**：科目と配点（例：英200・数400・物400）、数Ⅲの有無、面接・小論文
- **難易度**：Kei-Net の共テボーダー得点率・二次偏差値（年度を書く）
- **私大のとき**：入学金・**延納（二段階手続）**の可否 ― 国公立の発表（前期 3/6〜）まで待てるかが大事
- **そのほか**：キャンパスの場所、新設・改組、定員の増減

## 3. 守ること

- **曜日は計算で検算**（`python -c "import datetime;print(datetime.date(2027,2,25).strftime('%a'))"`）。
- 2027年度の情報が見つからなければ前年度の日付を使い、`tentative: true` と `note: 昨年度の日程（目安）` を付ける。黙って推測しない。
- 数字・日付には必ず出典URL（`url` / `source`）。
- **本人が特定される情報は書かない**（学校名・クラス・フルネーム）。

## 4. 比べるとき

聞かれたら、まず会話で次の表を出す（ページに入れるかは確認してから）：

| 大学・学部 | 日程 | 共テボーダー | 二次偏差値 | 二次科目（配点） | 共テ配点 | 一言 |
|---|---|---|---|---|---|---|

- 美幸の目安：日東駒専〜GMARCH 理工レベル → 共テ 55〜65% が**実力相応**。それより上は**チャレンジ**、下は**安全寄り**。
  模試の結果を聞いたら、その得点率で判定し直す。
- 前期・中期・後期で1校ずつ組めるか、二次の型（英＋数／数＋物／数のみ）がそろうかも一言そえる。

## 5. ページに入れる

- 受けると決めた → `targets`（日程は `dates`、締切・試験日には `remind: true`）。書き方は `juken` スキル。
- 候補として見せたい → `recommend` の該当する系統の `examples` に
  `{name, schedule, border, level, note, url}` で追加（`level` は チャレンジ／実力相応／安全寄り）。
- 終わったら `python scripts/juken.py render` → `python -m unittest discover tests` →
  スクリーンショットで確認 → commit・push。
