出願の組み方

  1. 前期・中期・後期で1校ずつ。前期は本命（実力相応、例：静岡大・信州大・新潟大の工学部）。
  2. 中期は公立の共テ高得点型（諏訪東京理科・兵庫県立 理）か、チャレンジ（大阪公立 工）。
  3. 後期は前期よりボーダーが +7〜10% 高いので、共テのみ・面接のみの学科（新潟大 工、群馬大 理工、富山県立大）で拾う。
  4. 1/18 の自己採点で最終決定。ボーダーとの差が −3% 以内なら出願可、+5% 以上なら一段上げる。
  5. 二次の型を「英＋数」「数＋物」「数のみ」のどれかに寄せると、対策が分散しない。
  6. 私大は国公立前期の発表（3/6〜）より先に入学手続締切が来る。東洋大（基礎学力テスト型・共テ利用）などで押さえを確保。学校からの推薦は専願が多いので、国公立を受けるなら使えるか先生に確認。

今年の変更点（これだけは知っておく）

  • 共通テストの出願はWebのみ（2年目）

    高3も一人ひとりが自分のマイページで出願。受験票も12/4からマイページで取得して A4 で印刷（去年より6日早い）。スマホ画面は不可、顔写真付きの身分証も必要。 出典

  • 成績は自己採点で出願

    大学への成績提供は2/2以降で、本人への事前の成績通知はない。出願時に希望した人だけ、4/1〜4/30 にマイページで成績を見られる（300円）。 出典

  • 新課程の科目だけで実施

    旧課程の経過措置科目はなし。理系は「数学①（Ⅰ・A）」「数学②（Ⅱ・B・C）」「情報Ⅰ」が2日目に集中する。 出典

  • 共テ出願者は 490,725人（前年同時点より547人減）

    現役 410,405人（−6,560）、既卒 80,320人（+6,013）。確定志願者数は12月上旬に発表予定。 出典

  • 推薦・総合型で面接が必須に（文科省 実施要項）

    年内入試が学力試験だけに偏らないよう、総合型・学校推薦型では面接による評価が必要に。言語能力・数理的思考力の評価にも配慮。 出典

  • 英検 第3回は共テ追試と同じ日

    一次 1/24（日）、結果は 2/15。一般選抜の出願には間に合わないことが多いので、使うなら S-CBT（12月〜）も検討。 出典
