出願の流れ（どうやって出願するの？）

① 国公立（第一志望）

共テの点＋二次試験で決まる。共テのあとに出願先を決めるのがポイント。前期・中期・後期で1校ずつ出せる。共テを中国語で解いたら、「中国語OK」の大学だけになる。

  1. 1/16・17共通テストを受ける
  2. 1/18自己採点 → 予備校のリサーチに出す河合塾・駿台ベネッセなどに自己採点を送ると、志望校の判定が返ってくる
  3. 〜1/24出願先を決める（前期・中期・後期）リサーチの判定とボーダーを見て、家族・先生と相談
  4. 1/25〜2/3大学のサイトでWeb出願入力 → 検定料 17,000円を払う → 共テの受験番号を入力（成績は大学がセンターから取り寄せる）→ 調査書などを郵送。締切日必着の大学が多い
  5. 〜2/10前期の第1段階選抜（足切り）の結果二段階選抜をする大学だけ
  6. 2月中旬受験票をWebで印刷
  7. 2/25〜前期の個別試験 → 3/6〜10 合格発表
  8. 3/15まで前期で合格したら入学手続手続きすると中期・後期は受けても合格にならない
  9. 3/12〜後期（中期は3/8〜）→ 3/20〜24 発表 → 3/27 手続

② 私大の一般選抜（MARCH・東洋）

大学ごとの試験の点で決まる。外国語はどこも英語（中国語では受けられない）。出願は共テ前後の1月。大学ごとに締切がバラバラなので一覧にしておく。

  1. 11月〜12月募集要項を読む・Web出願のアカウントを作る正式な要項は11月上旬から公開
  2. 1月上旬〜下旬大学のサイトでWeb出願検定料は1回 約35,000円（同じ大学で複数出すと割引あり）。調査書を郵送（消印有効の大学が多い）
  3. 試験の1〜2週間前受験票をWebで印刷
  4. 2/1〜2/15ごろ試験 → 2月中旬〜下旬に合格発表
  5. 2月下旬入学手続（1次）＝入学金を払う延納できる大学（明治・青学・中央）は、残りの学費を国公立の発表のあとまで待てる

③ 私大の共テ利用

共テの点だけで決まる（大学の試験を受けに行かなくていい）。締切が共テより前なのに注意。共テを中国語で解くと、出せるのは立教 理・法政 理工C方式くらい（明治・青学・中央・東洋は英語指定）。

  1. 1/15までWeb出願（MARCHはどこも1/15締切）共テの受験番号を入力。検定料は 約15,000〜18,000円
  2. 1/16・17共通テストを受ける（これが試験）
  3. 2月中旬合格発表（例：法政 2/9、中央 2/13、明治 2/15）
  4. 2月中旬〜下旬入学手続（1次）一般選抜と同じく、延納できるかを確認

④ 合格したら（入学手続）

私大の締切は国公立の発表より前に来る。お金の流れを先に家族で決めておく。

  1. 私大の1次締切押さえの1校に入学金を払う（約20〜24万円）入学金は辞退しても戻らない
  2. 延納の締切（3月中旬〜下旬）国公立の結果を見てから残りの学費を払う／払わない
  3. 3/6〜国公立に合格 → 3/15までに手続 → 私大は辞退の手続
  4. 3/31まで私大を辞退すれば、入学金以外（授業料など）は返ってくる

  • 調査書：担任の先生に発行を頼む。出す大学の数＋予備（封をした状態で使う）

  • 検定料の目安：国公立 17,000円/校、私大一般 約35,000円/回、共テ利用 約15,000〜18,000円/回
